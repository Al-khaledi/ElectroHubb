# ElectroHub — النسخة الأمامية بدون قاعدة بيانات

موقع تعليمي ثابت يعمل باستخدام HTML وCSS وJavaScript فقط. لا يحتاج PHP أو MySQL أو XAMPP أو اتصالاً بخادم.

## تشغيل الموقع
1. فك ضغط المجلد `ElectroHub_Static`.
2. افتح `index.html` في المتصفح مباشرة.
3. يفضّل استخدام VS Code مع إضافة Live Server للتطوير، ثم اختيار Open with Live Server.

## الصفحات
- `index.html`: تعريف المنصة والرئيسية.
- `lessons.html`: قائمة الدروس مصنفة إلى مبتدئ ومتوسط ومتقدم.
- `lesson.html?id=...`: صفحة شرح الدرس والفيديو والأدوات.
- `store.html`: متجر تعريفي وروابط بحث شراء خارجية، بلا سلة.
- `assistant.html`: صفحة تعريف المساعد.
- `assistant-chat.html`: المحادثة مع قاعدة المعرفة المحلية.
- `simulator.html`: محاكي حسابي مبسط لدائرة LED وروابط محاكيات خارجية.

## أين أضع روابط فيديوهات YouTube؟
افتح الملف:
`assets/js/data.js`

ابحث عن مصفوفة `window.LESSONS`. كل درس يحتوي خصائص `youtubeId` و`youtubeTitle` و`youtubeLanguage`. أضفت روابط فيديوهات مقترحة للدروس الحالية، ويمكنك استبدالها لاحقاً.

مثال رابط يوتيوب:
`https://www.youtube.com/watch?v=ABC123xyz00`

المعرّف هو الجزء بعد `v=`، أي `ABC123xyz00`. ضع هذا الجزء فقط:
`youtubeId: 'ABC123xyz00', youtubeTitle: 'عنوان الفيديو', youtubeLanguage: 'العربية'`

مثال داخل تعريف درس:
`{id:'ohm', title:'قانون أوم وقراءة المقاومة', ..., youtubeId:'ABC123xyz00', ...}`

إذا كان الرابط من نوع Shorts أو رابط مشاركة `youtu.be`، استخرج المعرّف من الرابط أيضاً. لا تضع الرابط كاملاً داخل youtubeId. اترك القيمة فارغة `''` إذا لم تضف فيديو. سيظهر الفيديو تلقائياً داخل صفحة الدرس عند فتحه، ويظهر أسفله عنوان الفيديو ولغته ورابط لفتحه على YouTube.

## الفيديوهات المضافة
تم ربط الدروس الحالية بفيديوهات تعليمية مناسبة. بعض موضوعات الإلكترونيات المتقدمة لا تتوفر لها شروحات عربية واضحة ضمن النتائج التي أمكن التحقق منها، لذلك أضيفت لها فيديوهات باللغة الإنجليزية مع توضيح اللغة أسفل المشغل. يمكن تغيير الفيديو في أي وقت بتعديل `youtubeId` و`youtubeTitle` و`youtubeLanguage` في `assets/js/data.js`.

## كيف أضيف درساً جديداً؟
داخل `assets/js/data.js` أضف كائناً جديداً إلى `window.LESSONS` مع الحقول:
- `id`: معرف إنجليزي فريد بدون مسافات، مثل `diode`.
- `title`: عنوان الدرس.
- `level`: واحدة من `مبتدئ` أو `متوسط` أو `متقدم`.
- `duration`: المدة المقترحة.
- `desc`: وصف قصير.
- `youtubeId`: معرف فيديو يوتيوب أو نص فارغ.
- `tools`: مصفوفة أسماء الأدوات.
- `body`: شرح الدرس.
ثم سيظهر تلقائياً في صفحة الدروس. رابط صفحته يكون `lesson.html?id=diode`.

## كيف أضيف قطعة للمتجر؟
أضف كائناً إلى `window.PRODUCTS` في `assets/js/data.js` بالحقول نفسها المستخدمة في المنتجات الحالية: `id`, `name`, `category`, `icon`, `desc`, `use`, `search`. روابط Amazon السعودية وNoon وAliExpress تتولد تلقائياً من عبارة البحث `search`.

## المساعد الذكي — توضيح مهم
المساعد في هذه النسخة أغنى من الردود القصيرة؛ يحتوي شروحات وأمثلة حسابية وقواعد للتعامل مع قانون أوم وLED والقدرة والمكثفات والترانزستورات وNE555 والملتيميتر وArduino/ESP32 والسلامة واستكشاف الأعطال. يعمل محلياً داخل المتصفح ولا يرسل البيانات إلى خادم. لكنه ليس نموذجاً توليدياً متصلاً بالإنترنت، لذلك لا يستطيع معرفة كل سؤال جديد أو التحقق من معلومات حديثة. لتحويله إلى ذكاء اصطناعي توليدي حقيقي يلزم لاحقاً ربطه بخدمة API من خلال خادم آمن، وعدم وضع مفتاح API داخل JavaScript الظاهر للزوار.

## المحاكي
المحاكي الداخلي يحسب التيار والقدرة التقريبية في دائرة مصدر جهد + مقاومة + LED وفق قانون أوم. هو نموذج تعليمي مبسط وليس محرك محاكاة كهربائية كاملاً، ولا يحاكي تغير خصائص LED مع الحرارة أو التفاوتات الفعلية. استخدم روابط Falstad وTinkercad وWokwi وCircuitVerse وEasyEDA وEveryCircuit للتجارب المتقدمة.

## تنبيهات
- لا توجد قاعدة بيانات أو تسجيل دخول أو سلة أو مدفوعات.
- المتجر يعرض روابط بحث خارجية؛ الأسعار والتوفر والبائعون تتغير.
- استخدم دوائر منخفضة الجهد للتعلم. لا تجرب كهرباء المنزل.
